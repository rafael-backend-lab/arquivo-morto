# Arquivo Morto — Deploy Público

## Objetivo
Preparar e publicar o projeto Arquivo Morto em URL pública para avaliação externa.

## Validações
- Build local obrigatório antes do deploy.
- Commit local antes da publicação.
- Deploy público via Vercel em produção.

## Observação
Arquivos não rastreados experimentais como claude_arquivo_morto_v2.md e src/assets/ não são adicionados automaticamente.
