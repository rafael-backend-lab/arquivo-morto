Regra visual:
As imagens desta pasta devem ser gráficas/cinematográficas. Não usar apenas logo, título ou texto do filme. A imagem precisa mostrar criatura, monstro, zumbi, laboratório, cadáver reanimado, personagem marcante ou cena visualmente reconhecível.
